# Expenses-tracker
A Python CLI expense tracker with JSON storage. Add, edit, delete, filter, sort, and search expenses, track your wallet balance, and view stats like totals, averages, and highest/lowest spend. Includes a pandas/matplotlib script for category breakdowns, spending charts, and Excel export.
## How to Use

1. **Download the analysis and expense files**
   cd expense-tracker
```

2. **Install the required libraries**
```bash
   pip install pandas matplotlib
```

3. **Run the tracker in your terminal**
```bash
   python expenses.py
```

4. **Use the menu** to add, view, edit, delete, search, or sort expenses, check stats, or manage your budget.

5. **Run the analytics script** to see charts and export to Excel
```bash
   python analysis.py
```
